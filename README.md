# AIM PLAY

Fun learning games for kids — play right in your browser, no install needed.

## How to play

1. Open `index.html` in any modern browser (phone, tablet, or computer).
2. Pick a game card, or tap **Spin** to let it choose for you.
3. Filter by category — English, Science & Health, or Arcade & Skill.
4. Tap a game to start playing instantly.

## What's inside

- **A games** — English, memory, matching, and typing practice.
- **B games** — health, science, and phonics.
- **C games** — arcade and brain skills.
- **Bonus** — extra games sorted by category.

All games are Thai-language and work offline once opened. Just open `index.html` and play.
